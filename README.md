# South African Microloan Funnel & Credit Risk Analysis (SQL Server)

## 1. Project Overview
Using **Microsoft SQL Server (T-SQL)**, this project analyzes customer drop-off rates, loan approval turnaround times, and early repayment risk for a South African digital microlender.

## 2. Repository Structure
* `01-Database-Setup/setup_database.sql` — Creates the relational database, tables, and sample South African loan dataset.
* `02-Business-Queries/funnel_and_risk_queries.sql` — SQL queries answering key business questions on funnel conversion, SLA performance, and default risk.
* `03-Insights-Summary/Key_Findings.md` — Plain-English business recommendations based on the query outputs.

## 3. Tools Used
* **Database:** Microsoft SQL Server & SQL Server Management Studio (SSMS)
* **Concepts:** Relational Tables, Primary/Foreign Keys, `JOIN`, `GROUP BY`, `CASE` Statements
